# FORJA - Contexto Geral

Projeto ERP para clubes de tiro. Tecnologias: Spring Boot, Angular, PostgreSQL, Flyway, JWT. Módulos concluídos: Dashboard, Clientes, Categorias, Produtos, Raias, Agendamentos. Em andamento: Estoque. Futuros: Vendas, Relatórios, Acervo. Padrão: arquivos completos, arquitetura modular, componentes List/Details/Form + Pages.
